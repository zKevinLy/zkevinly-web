# Security Policy

## Supported versions

Only the latest release (the current `main` branch, deployed to zkevinly.com) receives
security fixes.

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/zKevinLy/zkevinly-web/security/advisories/new)
(Security tab, then "Report a vulnerability"). Do not open a public issue for security problems.

Please include a description of the issue, steps to reproduce it, and the affected URL or file.

## Disclosure policy

- You will get an acknowledgement within 7 days.
- I aim to confirm the issue and share a remediation plan or timeline within 30 days.
- Fixes are released first, then the vulnerability is disclosed publicly (coordinated
  disclosure), with credit to the reporter if they want it.

## Scope

This repository is the public website for zkevinly.com. The homelab (`*.lab.zkevinly.com`)
is private infrastructure and is not covered here.
